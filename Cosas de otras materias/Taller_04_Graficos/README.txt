Taller 04 - Graficos obligatorios

Contenido:
- taller_04_graficos_obligatorios.py: programa principal.
- requirements_taller_04.txt: dependencias, por si se quieren instalar manualmente.
- ejecutar_guardar_todos.bat: genera todos los graficos en PNG.
- Taller_04_Intro_Campo_Escalar.pdf: enunciado de referencia.

Uso facil:
1. Extraer el ZIP.
2. Abrir ejecutar_guardar_todos.bat.
3. Si faltan numpy o matplotlib, el programa intenta instalarlos automaticamente.
4. Los graficos se guardan en la carpeta graficos_taller_04.

Uso por consola:
py taller_04_graficos_obligatorios.py --guardar

Para elegir ejercicios:
py taller_04_graficos_obligatorios.py --ejercicio 2 4 12 --guardar

Instalacion manual opcional:
py -m pip install -r requirements_taller_04.txt
